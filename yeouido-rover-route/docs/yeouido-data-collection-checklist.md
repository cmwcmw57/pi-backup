# 여의도 주행 데이터 수집 체크리스트 (2026-10-18)

## 목적
시뮬과 실제의 차이를 정량화하고, 이를 바탕으로 대회용 모래 맵 주행 알고리즘을 검증한다.

## 전제
- STL(현장 지형 + 모래 맵 형상)은 팀원이 줄자 실측으로 정확하게 제작해 전달한다 → 형상 검증은 생략.
- 따라서 오늘은 **STL에 없는 정보(외관, 센서 특성, 동역학, 조명)** 수집에 집중한다.
- 정답값(GT)은 줄자로 측정한다.

---

## 1. 외관 (시뮬 텍스처용)
- [ ] 모래 표면 컬러 사진: 위에서, 줄자/자를 함께 넣어 스케일 기록 (3~5곳)
- [ ] 반복되지 않는 넓은 영역 사진 우선 (시뮬 0.25 m 타일 반복 문제 대응)
- [ ] 맵 전경 + 주변 바닥 컬러 사진
- [ ] 체크포인트마다 D435 IR 흑백 프레임 1장씩 (알고리즘이 보는 영상, 시뮬 렌더와 같은 자세로 비교용)
- [ ] 컬러 사진은 노출 고정

## 2. 센서 특성
- [ ] 정지 상태 IMU 5분 이상 — 주행 시작 전, 종료 후 각 1회 (bias/noise)
- [ ] 카메라·IMU **장치 타임스탬프**와 수신 시각을 모두 저장 (−47 ms 오프셋 재확인)
- [ ] 프레임 드롭, IMU 누락 횟수 로그
- [ ] 노출/게인, projector on/off 상태 기록
- [ ] 깊이 원본(z16)과 IR 좌우 영상 저장 (용량 허용 시)

## 3. 동역학
- [ ] 모래 위 5 m 직진 × 반복 (같은 명령) → 줄자로 실제 이동 거리 → 슬립률
- [ ] 단단한 바닥에서도 동일 측정 (비교 기준)
- [ ] 모래 위 주행 중 IMU 진동 기록 (단단한 바닥과 구분)
- [ ] 주행 전후 바퀴 자국(rut)·모래 표면 사진
- [ ] 모터 명령(cmd)과 바퀴 속도/엔코더 로깅 여부 확인 → 없으면 추가

## 4. 정답값 (GT)
- [ ] 출발 위치와 heading을 STL 기준점에서 줄자로 실측 (cm, 도 단위)
- [ ] 직선 구간 1 m 간격 분필/테이프 마킹, 각 점에서 2~3초 정지
- [ ] 출발점으로 되돌아오는 루프 1회 이상 (시작/끝 위치 오차)
- [ ] 같은 경로 왕복 2~3회 반복

## 5. 환경/메타데이터
- [ ] 시간대, 날씨, 하늘 사진 1장, 그림자 방향
- [ ] 카메라 pitch 20°(확정값) 유지 확인
- [ ] 배터리 전압
- [ ] 노면 종류 메모 (모래 / 그 외)

---

## 우선순위 (시간이 부족할 때)
1. 정지 IMU 5분 + 타임스탬프 로그
2. 체크포인트 정지 주행 + 출발 자세 실측
3. 모래 직진 5 m 슬립 측정
4. 텍스처용 컬러 사진
5. 나머지

## 미확인
- 엔코더/모터 명령 로깅 여부
