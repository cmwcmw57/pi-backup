# 조향축과 구동축 기준점

기준: base_link, X 전방 / Y 왼쪽 / Z 위. 로커 0, 조향 0 자세. 단위 mm.
조향축은 서보 출력축과 휠 허브의 연결 기준점입니다.
구동축 기준점은 조향축에서 수직 아래로 내린 점과 구동 회전축의 교점입니다.

| 모듈 | 조향축 XYZ (mm) | 조향축 바로 아래 구동축 XYZ (mm) | 실제 URDF wheel_joint 원점 XYZ (mm) |
|---|---|---|---|
| FL | (+102.431, +132.500, -45.313) | (+102.431, +132.500, -114.313) | (+102.431, +142.030, -114.313) |
| FR | (+102.431, -132.500, -45.313) | (+102.431, -132.500, -114.313) | (+102.431, -142.030, -114.313) |
| RL | (-102.431, +132.500, -45.313) | (-102.431, +132.500, -114.313) | (-102.431, +142.030, -114.313) |
| RR | (-102.431, -132.500, -45.313) | (-102.431, -132.500, -114.313) | (-102.431, -142.030, -114.313) |

조향축에서 구동축까지의 수직 거리는 69.000 mm입니다.
기존 wheel_joint 원점은 위 기준점에서 축 방향으로 바깥쪽 9.530 mm 이동한 점입니다.
두 점은 같은 회전축 위에 있습니다. 요청한 수직 아래 기준점을 표에 별도로 제공합니다.
좌표 정리에 따라 기존 URDF의 조립 형상·질량·관절 변환은 변경하지 않았습니다.
